## Image generation prompt

Use case: photorealistic-natural. Asset type: a neutral sample image bundled locally with an open-source React component documentation example. Primary request: a calm fictional mountain lake with pale stones at the shoreline, distant tree-covered hills and soft morning light, natural photographic texture. Composition: simple wide landscape, approximately 3:2, clear foreground and background, no people or identifiable landmarks. Constraints: no text, no logos, no watermarks, no borders, no collage, no existing artwork or brand references.
