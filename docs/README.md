# Documentation

[Common standards and resource contracts](common/) are maintained once and also
ship with generated workspaces. [Source repository guides](template-repository/)
cover generation, template contribution, source verification and repository policy.

The user-project-specific guide sources live in
[the monorepo scaffold](../scaffolds/monorepo/docs/); its dedicated README and
AGENTS describe generated application ownership. Selected packages keep their own
README/API/license documentation. Engineering plans are maintained outside this repo.
